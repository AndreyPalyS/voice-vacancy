# Секреты и данные

- `.env`, `.env.*` (кроме `.env.example`), логи, node_modules, dist и временные результаты не отслеживаются Git.
- GROQ_API_KEY используется только сервером. В Sites он хранится как runtime secret. В исходниках, manifest, клиентском bundle и deployment-архиве его нет.
- GitHub Actions запускается без настоящего AI-ключа. Проверка узнаваемых ключей: `npm run check:secrets`.
- Черновик хранится в localStorage этого браузера. AI получает ответы на пять вопросов, браузерное распознавание может отправлять речь провайдеру браузера. Не публикуйте чувствительные ответы в примерах или видео.
- Сервер не логирует ключи и тексты ответов. Браузерный HTML из модели не исполняется.
- Worker ограничивает размер входа и частоту запросов внутри экземпляра. Ограничение не заменяет глобальный контроль бюджета и не гарантирует защиту от распределённого злоупотребления.

Если ключ оказался опубликован, отзовите его в Groq, создайте новый и обновите серверное окружение. Затем удалите секрет из истории; одна очистка истории не делает старый ключ безопасным. Не отправляйте секреты в публичные Issues.
